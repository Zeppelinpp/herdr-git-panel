# Git panel

## Language

**Working tree**: Files currently checked out in the repository, including unstaged, staged and untracked changes.

**Comparison branch**: A local branch or an already fetched remote branch selected as the base for comparing committed changes with HEAD.

**Committed on branch**: Committed changes between the comparison branch's merge base with HEAD and HEAD. This excludes working-tree changes.

**Repository change**: A change to branch identity, refs or repository settings that can affect history and committed comparisons.

**Working-tree change**: A file, staging or ignore-rule change that can affect the working-tree view without changing commit history.

**Commit history**: The current branch's commits and merge relationships, with independently expanded file statistics and a selected commit or file.
